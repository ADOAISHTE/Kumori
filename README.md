# Kumori: tu negocio, en calma

Página académica para presentar la propuesta de un ERP intuitivo. Datos ficticios; no es un sistema operativo ni guarda información.

## Archivos de entrega

index.html contiene la estructura y el contenido. kumori.css define el diseño. assets incluye las imágenes y Bootstrap Icons. Readme-Imperial.txt conserva la atribución original de Imperial, de BootstrapMade. El contenido y los estilos se adaptaron a Kumori con ayuda de IA.

La entrega funciona sin JavaScript. Los ejemplos y el menú utilizan details y summary. El JavaScript de la primera versión se conserva localmente, pero no se incluye en el paquete.

## Publicar

Subir el contenido del paquete a la raíz del repositorio, conservando las carpetas. En Settings > Pages, seleccionar Deploy from a branch, main y /(root), y guardar.

Fuente: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Para explicar el proyecto

- header y nav organizan la navegación; main contiene las secciones; footer cierra la página.
- Los enlaces con # apuntan al id de cada sección.
- Las imágenes tienen src, alt, width y height; CSS mantiene sus proporciones.
- Grid y Flexbox distribuyen elementos; las media queries adaptan el diseño al ancho disponible.
- details y summary permiten abrir y cerrar contenido con HTML.
- Se conserva la atribución a la plantilla y se distingue el concepto del producto real.
